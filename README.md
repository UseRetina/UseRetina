# Retina

Retina is a crypto portfolio tracker for people whose money is spread across DeFi. Paste EVM, Solana, Hyperliquid and Polymarket addresses, add gold, silver or anything else by hand, and everything lands in one read-only portfolio. See the APY each position quotes beside what it actually earned, ask questions about any of it with Ask Retina, a built-in AI assistant, and get an alert before anything matures.
