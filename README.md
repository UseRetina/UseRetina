# Retina

Retina is an AI crypto portfolio tracker for people whose money is spread across DeFi. Paste EVM, Solana, Hyperliquid and Polymarket addresses, and every position lands in one read-only portfolio. Ask Retina, the built-in AI assistant, answers questions about it in plain language, with every number calculated by Retina itself. See the APY each position quotes beside what it actually earned, and get an alert before anything matures.
